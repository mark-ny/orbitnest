Contributing to OrbitNest

Thank you for your interest in contributing to OrbitNest!

OrbitNest aims to bring browser sessions, Linux environments, terminals, and development tools together in one flexible workspace platform for Termux, Linux, and Windows.

How to Contribute

1. Fork the repository on GitHub.
2. Create a feature branch for your changes.
3. Make your changes and add tests where appropriate.
4. Run relevant tests and check that existing functionality still works.
5. Commit your changes with a clear message.
6. Open a Pull Request describing what you changed, why it matters, and how you tested it.

Contribution Areas

- Termux and Android compatibility
- Linux and Windows support
- Workspace lifecycle and runtime adapters
- Browser and terminal access
- Security, authentication, and permissions
- File management and persistent storage
- Documentation, testing, and bug fixes

Guidelines

- Keep changes focused and explain their purpose.
- Follow the existing project structure and coding conventions.
- Never commit passwords, API keys, tokens, or private configuration.
- Do not claim a feature works on a platform unless it has been tested there.
- Include tests for bug fixes and new functionality where practical.
- Discuss major architectural changes in an issue before implementing them.

Pull Requests

Pull Requests are reviewed before merging. Maintainers may request changes to improve security, reliability, compatibility, or maintainability.

Thank you for helping improve OrbitNest!
